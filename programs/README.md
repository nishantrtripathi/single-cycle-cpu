# Programs

| Folder | Contents |
|---|---|
| `asm/` | Hand-written RISC-V assembly (`.S`), v1 subset only |
| `hex/` | Generated by `scripts/asm2hex.sh` -- **don't edit by hand** |
| `expected/` | Final architectural state each program must reach |

## Rules for every program
1. Use only instructions from ADR-001 (no JAL/JALR/LUI in v1).
2. End with a halt loop: `halt: beq x0, x0, halt`
3. Have a matching `expected/<name>.txt`.

## Expected-file format
One check per line, `#` for comments:
```
# reg  value
x1  0x00000005
x2  0xFFFFFFFF
# mem  byte-address  value
mem 0x00000010 0x0000002A
```
